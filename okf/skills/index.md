# Skills

Portable `skills/<name>/SKILL.md` instructions paired with CLI tools.

* [run-pipeline](/skills/run-pipeline/SKILL.md) → `pipeline.py`
* [discover-jobs](/skills/discover-jobs/SKILL.md) → agent shortlist + `applications/shortlists.md` (`pipeline.py` batch)
* [tailor-resume](/skills/tailor-resume/SKILL.md) → agent-run resume tailoring (`ai_tailor.py` fallback)
* [tailor-coverletter](/skills/tailor-coverletter/SKILL.md) → agent-run cover letter tailoring (`ai_tailor.py` fallback)
* [audit-application](/skills/audit-application/SKILL.md) → agent-run audit (`audit.py` batch fallback)
* [build-documents](/skills/build-documents/SKILL.md) → `build.py`, `bundle.py`
* [research](/skills/research/SKILL.md) → agent web or `research.py`
* [find-contacts](/skills/find-contacts/SKILL.md) → agent web or `find_contacts.py`
* [networking-outreach](/skills/networking-outreach/SKILL.md) → templates
* [follow-up](/skills/follow-up/SKILL.md) → `followup.py`
* [track-application](/skills/track-application/SKILL.md) → `track.py`
* [new-application](/skills/new-application/SKILL.md) → single-application orchestrator (`new_application.py` scaffolds, `pipeline.py` batch fallback)
